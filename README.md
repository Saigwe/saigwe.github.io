# saigwe.github.io

Personal portfolio for **Stanley Igwe**, Lead Data (Analytics) Engineer. Live at **https://saigwe.github.io**.

Plain HTML, CSS and a little JavaScript. No build step, hosted on GitHub Pages.

## Adding a project
1. Make sure the repo is **public** and contains nothing confidential (no client data, take-home tasks, credentials or logs).
2. Add the GitHub topic **`portfolio`** to the repo (repo page → ⚙️ next to *About* → Topics).
3. It appears automatically under *Projects* (via the GitHub API). To make it the featured project instead, edit the `feature` block in `index.html`.

When a "Currently building" item goes live, remove it from that list in `index.html`.
